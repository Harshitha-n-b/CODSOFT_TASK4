# CODSOFT TASK 4 - SMS Spam Detection

## 📱 Project Overview

This project is an SMS Spam Detection system developed using Machine Learning.

The model classifies SMS messages into two categories:

- **Ham** – Legitimate SMS
- **Spam** – Unwanted or fraudulent SMS

## 🎯 Objective

To build a Machine Learning model that can automatically identify whether an SMS message is spam or legitimate.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- TF-IDF
- Logistic Regression
- Google Colab

## 📊 Dataset

The project uses an SMS Spam dataset containing labeled SMS messages.

Each message is classified as either:

- `ham`
- `spam`

## 🤖 Machine Learning

### TF-IDF

TF-IDF (Term Frequency-Inverse Document Frequency) converts text messages into numerical features that can be processed by a Machine Learning model.

### Logistic Regression

Logistic Regression is used to classify the numerical features into two classes:

- Ham
- Spam

## 📈 Model Evaluation

The model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## 🧪 Custom SMS Prediction

The trained model was also tested with new SMS messages to determine whether they were spam or legitimate.

## 💾 Model Saving

The trained Logistic Regression model and TF-IDF vectorizer were saved using Joblib for future use.
